# Prepare to Use Your Command Station

Before you can use you use your purchased or self-built **EX-CommandStation**, you will need to do some preparatory work before you can test it and run your trains.

Depending on whether or not you purchased an **EX-CSB1** or you self built your own **EX-CommandStation**, the instructions are different.

- If you have purchased an **EX-CSB1** you can go straight to the section on [physically connecting your command station](#physical-connection-to-your-layout)
- If you have self built your own **EX-CommandStation** continue to the next section on [Installing the EX-CommandStation software](#installing-the-ex-commandstation-software)

## Installing the EX-CommandStation software

This step is only needed for self built EX-CommandStations, or if you wish to update or enhance your **EX-CSB1**.

This software is ***only*** needed for self-built EX-CommandStations, or if you wish to update or enhance your **EX-CSB1**.

The **EX-CommandStation** software is what allows your self-built EX-CommandStation hardware or purchased EX-CSB1 to function as a simple, and powerful, DCC and DC Command Station.  If you purchased the **EX-CSB1**, this software is already installed.  The software supports much of the NMRA Digital Command Control (DCC) standards, including:

- Simultaneous control of multiple locomotives
- Control of all cab/loco functions (F0-F28 and F29-F68)
- Control of accessory / function decoders (F0-F28 and F29-F68)
- Main Track: Write configuration variable (CV) bytes and set/clear specific CV bits (aka Programming on Main, or POM)
- Programming Track: Same as the main track with the addition of reading CV bytes

along with other advanced features, such as:

- A wiThrottle Server implementation for instant compatibility with popular throttles (controllers)
- General purpose inputs and outputs (I/O) for extensibility
- I2C bus for controlling accessories with I2C capability
- JMRI integration
- **EXRAIL** Automation and Animation scripting that can control everything on your layout, including the locos
Once you have assembled your self built **EX‑CommandStation** *hardware* you need to load our **EX‑CommandStation** [software](../products/ex-commandstation/index.md) onto it to make it usable.  There are several ways you can do so, but to make it as simple as possible we have created the [**EX‑Installer**](./installer/index.md) app.

Continue to the [Install the software](./installer/index.md) page to install the software, before proceeding to the physical installation.

## Physical Connection to Your Layout

Once you have a) purchased and **EX-CSB1**, or b) self built your **EX-CommandStation** and loaded the software onto it, you will need to connect it to your layout and programming track to test it and to run your trains.

Depending on whether or not you purchased an **EX-CSB1** or you self-built your own **EX-CommandStation**, the instructions for connecting to your layout and programming track will be slightly different.

- See the [Connecting your **EX-CSB1**](./connecting/connecting-ex-csb1.md) page if you have purchased an **EX-CSB1**.
- See the [Connecting your self-built **EX-CommandStation**](./connecting/connecting-diy.md) page if you built your own.

----

## Testing

Once you have connected your **EX-CSB1** or **EX-CommandStation** to your layout and programming track you should test it to confirm it is working correctly.

You need to test with a locomotive equipped with a DCC decoder (either a standard or sound decoder). Ideally, it should be a loco already proven to work on DCC. Otherwise, if you have a problem, you may not be able to tell if the problem is the decoder or the EX‑CommandStation.
