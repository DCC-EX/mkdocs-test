# Serial commands to: Set signal colour

Serial command to set the colour of a signal.

``</ RED «signal»>``
``</ AMBER «signal»>``
``</ GREEN «signal»>``

----

## Commands

* ``</ RED «signal»>`` = Set signal colour
* ``</ AMBER «signal»>`` = Set signal colour
* ``</ GREEN «signal»>`` = Set signal colour

## Parameters

* **signal**: defined **red** Vpin of the signal to control

## Response

none

----

## Notes

* regardless of the colour you wish to set, the **signal** parameter is always the Vpin of the *red* LED.
