# Downloading EX-Installer - Overview

The **EX-Installer** app needs to be downloaded to your PC and run from there.

Use these buttons to download an appropriate version.

[Windows x64](./download-win.md){ .md-button }
[macOS](./download-mac.md){ .md-button }
[Linux x64](./download-linux.md){ .md-button }

See these pages for additional information on how to run setup the app to run. (Especially for macOS and Linux):

- [Linux](download-linux.md)
- [Apple macOS](download-mac.md)
- [Microsoft Windows x64](download-win.md)

!!! IMPORTANT "Not supported on Windows 7 or rPi!"
    There is no support for **EX-Installer** on Windows 7, nor 32-bit operating systems such as Windows x32 or RaspberryPi OS.
