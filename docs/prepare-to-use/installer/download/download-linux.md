### Download and install on Linux

<!-- ==TODO== MEDIUM - Download and install on Linux - Add screenshots -->

!!! IMPORTANT "Not supported rPi!"
    There is no support for **EX-Installer** on 32-bit operating systems such as RaspberryPi OS.

- Download the Linux version of **EX-Installer** from [Linux x64](https://github.com/DCC-EX/EX-Installer/releases/latest/download/EX-Installer-Linux64){ .md-button }

- Right-click on the file, go to Properties, then the Permissions tab, and check "Allow executing file as program"
- Open a terminal window and navigate to that folder
- Run the installer with the following command:

```bash
    ./EX-Installer-Linux64
```
