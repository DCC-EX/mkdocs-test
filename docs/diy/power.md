# Selecting a power supply

You will require one *or two* power supply units to provide track power and to run the **EX-CommandStation** processor.

If you have used a **EX-MotorShield8874** then only one power supply is required.

If you have used a motor driver other than the **EX-MotorShield8874** (e.g. Arduino Motor Shield or Deek Robot Motor shield), then you will need *a second 7v power supply* to power the Microprocessor.
