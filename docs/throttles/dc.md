# DC Operation

**TrackManager** is a feature that lets you dynamically configure the power outputs of your **EX-CommandStation**.  It provides options to select regarding how power is set up on the ``MAIN`` or ``PROG`` output(s).  This includes featurs like: DCC modes, DC modes, DCC Auto Reverse mode, and a DCC Booster mode.

This capability is part of **TrackManager** and is built into your **EX-CommandStation**.  Read the following to explore this feature:

* [TrackManager](../enhance/trackmanager/index.md)
* [Running a Legacy DC layout](../enhance/dc-running.md)
