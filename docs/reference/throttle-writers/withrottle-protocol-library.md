# WiThrottle Protocol Library - WiThrottleProtocol

A WiThrottle protocol library is available to help develop throttle apps on ESP32 hardware.

The library implements the WiThrottle (as used in the **DCC-EX** **EX-CommandStation**, JMRI, and several other commercial command stations), allowing a device to connect to the server and act as a client (such as a hardware based throttle).

Details of the library, including instructions and examples, [is available here](https://github.com/flash62au/WiThrottleProtocol).

*This library is maintained independently from the **DCC-EX** project and any issues should be addressed via the instructions on the GitHub page.*

Note that use the [DCC-EX Native/Serial Command Protocol Library](./native-protocol-library.md) is recommned if your throttle will only ever connect to the an **EX-CommandStation**.
