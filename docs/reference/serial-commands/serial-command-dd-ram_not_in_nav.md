# <small>``<D RAM>``</small> <br/> Diagnostic display free RAM

Serial command to display free RAM.

## Command(s)

* ``<D RAM>`` = Diagnostic display free RAM

## Parameters

none

## Response

``Free memory=xxxx``

* **xxxx**: the amount of free ram

## Notes

* The response is displayed on the Serial Monitor only.
