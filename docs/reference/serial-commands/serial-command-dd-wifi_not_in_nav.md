# Serial commands to: WiFi diagnostics

Serial commands to provide WiFi diagnostics.

``<D WIFI ON>``
``<D WIFI OFF>``
``<D WIFI SHOW>``

----

## Command(s)

* ``<D WIFI ON>`` = Enable Wifi diagnostics
* ``<D WIFI OFF>`` = Disable Wifi diagnostics
* ``<D WIFI SHOW>`` = Show Wifi status
